    Review and submit

    save, download or test

    Save draft keeps the quest on the server under your account. Download gives you the .bin exactly as the server would serve it. Submit for testing puts it in your quest counter as a testing quest only you can load; the server assigns its quest id. The testing copy pays the reward money but no item rewards; once an admin approves the quest, it pays the rewards you set.
