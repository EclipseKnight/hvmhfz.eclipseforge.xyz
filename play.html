Play on Hunsterverse

Pick your path. Each one is a checklist: tick a step when it is done and this browser remembers it. Every step has one download, and the server settings have a copy button.

New on WindowsClient, patch, launcher, server and your first login. Linux / Steam DeckWith Wine. Steam Deck is not tested yet. Bringing a characterFrom another server: get your file, then import it.

New on Windows

Windows 10 or 11, 64-bit, about 8 GB free. The full text with screenshots is the Windows guide.

One-click installer (beta) Sets up the client, our patch and the launcher with Hunsterverse already added, then you press REGISTER in the launcher. Not yet tried on many PCs: if it fails, use the steps below and tell us in Discord. Windows may say "Windows protected your PC": choose More info, then Run anyway.

Download the installer

Full download (beta) The whole client (about 5.7 GB in 4 zip parts), already patched, with the launcher and Hunsterverse set up. Download all four parts, choose Extract All for each into the same folder, then run Finish-setup.bat.

Download the full client

  1. The folder Monster Hunter Frontier Online, about 5.5 GB. It comes from a community Google Drive folder, not from us, and the folder also holds server files you do not need.

    Client (Google Drive)

  2. Copy, do not move, so that dat and mhf.exe sit directly inside. Not in Program Files. Add the antivirus exclusion before you patch: mhf.exe is the file most often flagged, and a quarantine in the middle of a copy leaves a half patched install.

  3. Unzip Frontier_Patch.zip (50.9 MB) over the game folder. The launcher cannot fetch it on a connection slower than about 3 MB/s. The guide has a PowerShell script that also backs up the files it replaces: step 3 of the guide.

    Frontier_Patch.zip

  4. Extract it so that Mezeporta.exe sits next to dat, not in a subfolder. The launcher is by LilButter (GPL-2.0, source).

    Mezeporta-Windows.zip (v1.5.4)

  5. The game is 32-bit, so the x86 package is the one that matters.

    vc_redist.x86.exe

  6. Windows 10 and 11 do not ship the old D3DX libraries; without them you get "d3dx9_43.dll was not found".

    DirectX runtime

  7. Windows may say "Windows protected your PC": the launcher is not code-signed. Choose More info, then Run anyway, only for the file from the releases page above.

  8. FieldValueCopy
    NameHunsterverse
    Host129.213.54.221
    Launcher Port8080
    Game Port53310
    ModeAPI (the default)
    VersionZZ

    If API mode will not log in, use Launcher Port 53312 and Mode SignV1: it plays the same, without the news and banners.

  9. Make it on this site (you can do this first, before installing anything), or press REGISTER in the launcher: both make the same kind of account. The username is case-sensitive: Hunter and hunter are different accounts, so type it exactly the same way every time. Do not type a new name into LOG IN: the server refuses a name that was not registered. Then pick the Hunsterverse server, log in, create a character and launch. The launcher window closing is normal.

    Create an account

  10. Use the same username and password. The account page shows your link command; run it in the Hunsterverse Discord to get backups and the bot commands.

    Sign in

Linux / Steam Deck

Tested on Arch based systems (CachyOS) with Wine. Steam Deck is not tested yet: SteamOS cannot install packages with pacman and the launcher needs a system Wine, so the guide's method may not work there. If you try it, tell us in the Discord. The full text is the Linux guide, including other distributions.

One-click installer (beta) A script that sets up everything and adds Hunsterverse to the launcher. Run it with bash install-hunsterverse.sh. Steam Deck is not tested yet.

Download the installer

  1. The folder Monster Hunter Frontier Online, about 5.5 GB, from a community Google Drive folder. You need about 12 GB free in all.

    Client (Google Drive)

  2. Enable multilib, then install Wine, winetricks and the libraries the game needs. The exact commands: step 2 of the guide.

  3. Check that dat/, mhf.exe, mhfo.dll, mhfo-hd.dll, mhl.dll and mhf.ini are there.

  4. Unzip it over the game folder; the guide's script also backs up what it replaces: step 4.

    Frontier_Patch.zip

  5. By LilButter (GPL-2.0, source).

    Mezeporta-Linux.zip (v1.5.4)

  6. Three short steps with commands: prefix, wrapper and options. Follow the guide for these; they depend on your distribution and graphics card.

  7. FieldValueCopy

    Launcher Port8080
    Game Port53310
    ModeAPI (the default)
    VersionZZ

    If API mode will not log in, use Launcher Port 53312 and Mode SignV1: it plays the same, without the news and banners.

  8. Make it on this site, or press REGISTER in the launcher. The username is case-sensitive: type it exactly the same way every time. Then pick the Hunsterverse server, log in, create a character and launch. Do not type a new name into LOG IN: the server refuses a name that was not registered.

Bringing a character from another server

Only saves from the ZZ client work. A character from an older client version (G or earlier) cannot be imported.

  1. Follow the Windows or Linux checklist up to your first login. The import only goes into a character that was played once, so create a throwaway character, walk into town and quit.

  2. What you need depends on where your character is now:

    Where your character isHow to get the fileResult
    A server running a newer ErupeIn the Mezeporta launcher, select that server and use the character Export.An export .json: imports fully.
    A server with a Discord bot backup commandRun its backup command and keep the zip it sends.A .zip: send it as it is, do not extract it.
    Hunsterverse (another account)Discord /backup, or the Backups tab on the account page.Our .zip: imports fully.
    An older Erupe server, or the export fails with an error 500Ask the server's staff for your character's save files, as a zip.A zip of saves imports fully; a bare savedata file only replaces that part.
    A server on an older client (G or earlier)Not possible.Not usable: ZZ only.

  3. Sign in with your game account, open the Backups tab, choose the file and the character to import into, press Preview to see what changes, then Confirm.

    Account page, Backups tab

  4. On the account page, copy your link command and run it in the Hunsterverse Discord: /link with your code. Then run /import, attach the file and choose the character.

  5. Your warehouse, guild and guild box are kept by the server, not in the file, so they do not come with you. The account page's Backups tab lists what a backup holds.
