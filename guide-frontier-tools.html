Tools and References

Community tools for building sets and reading sigils, area maps for gathering, and quick-reference tables for armour upgrades and buffs.

MHSX2G armour set builder

MHSX2G is a tool for finding armour sets from criteria such as skills, number of each armour type and slots. The armour piece names are all in Japanese, but the main window is mostly English. The version the guide's author published includes unreleased monsters and upcoming event armours, so set your filters carefully to avoid gear you cannot get.

Taiwan-only armours have plain English names in every version of MHSX2G the guide published. Decorations use their real in-game names.

The Z2.3 version uses the latest Japanese data files as of the end of August 2018, with English selected by default. The guide's author hosted a download. It is a third-party program, so use it with the usual care.

Different. MHSX2G is a separate program and its armour names are Japanese, while our client shows English names that may not match. Hunsterverse has a browser-based armour set builder: pick skills and it finds sets. For what the skills do, see Armour skills.

Sigil Hunter

Sigil Hunter reads the skills on a sigil and prints them as text. It finds all sigils in a general sense. For example, it tells you that you have Ultra Rapid Fire, but not which ammo type it uses. The guide's author says it is no longer updated, and that you probably only want about five skills anyway. Press F1 at the top left of the sigil skill read-out for the updated notes.

The tool needs a Chinese system locale with the proper language packs, and the in-game font must be identical to the font in the guide's preview image, or it will not read properly. It also needs AutoHotkey (ahkscript.org). The guide gives the version as 20160106.

Unknown, not checked. The tool was made for the Taiwanese client's text and font. Whether it works with our English-patched client was not checked. To learn what each sigil does, see Sigils.

English Ferias and Loxxol script

This is a Tampermonkey-style userscript that adds basic translations to Ferias and Loxxol, two Japanese Monster Hunter Frontier data sites. It does these things:

  • Translates the hitbox quick link page on Loxxol.
  • Lets you view the individual Lv2 to Lv49 G Rank weapon upgrades.
  • Translates all loaded armour skills on armour pages when you hold the left mouse button on an armour type section (such as G Rank).
  • Translates all loaded armour skills on decoration and cuff pages when you click the fist icon at the top right of the page.
  • Translates all loaded weapon flags on weapon pages when you hold the left mouse button on a weapon type section's link (such as RNGou).

Firefox users need Tampermonkey or an older version of Greasemonkey to use the script. Chrome and other browsers need Tampermonkey. The guide gives the version as 1.201700101. Get Tampermonkey for Firefox or Chrome. The script file is ferias.user.js. Only install a userscript if you trust its source.

The hitbox page itself is on Loxxol.

Different. The script only translates two outside data sites for the official servers, and we do not link to them. On Hunsterverse, use the monster field guide for hitzones and the catalog for items and equipment.

OCR tools

OCR tools turn text in a picture into text you can copy or translate.

  • ABBYY FineReader is an excellent OCR program, and you can buy it on the ABBYY website.
  • Capture2Text is completely free. Its results are slightly worse.
  • There are also phone and tablet apps that read text from photos, such as Hanping.

Different. Menu, item, skill and quest names in our client are in English, from the translation patch, so you will need OCR much less than on the Taiwanese client.

  • Skill Rank Boost only affects some pre-G Rank skills.
  • Gou Attack is only added if you use Gou base weapons (Gou, Burst, Origin and so on).

Skill mechanics

The guide repeats its skill mechanics at the end of this quick-reference page. They are covered in full in Armour, Decorations and Skills:

  • Skill basics: the default limit of 10 active skills (11 or 12 at G Rank) and hidden skill priority.
  • Hybrid skills: Sword God +2, Gentle Shot +3, Blazing Majesty +2 and the grey skills that waste a slot.
  • Exotic, Tower and weapon skills: fixed skills that do not add points.
  • Other sources of skills: Skill Fruits (30 fruits for 3 Lottery G Coins) and Guild Cooking.
  • Muscle Boost and the Gou armour types table with the health needed for each piece count.

Different. Skill mechanics work the same. Skill Fruits are bought with Lottery G Coins, and the gacha only holds three zenny demos for now, so that route is not available yet.
