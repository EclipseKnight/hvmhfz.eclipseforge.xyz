      Event calendar

        One featured event at a time, back to back; every boundary is a Monday 03:00 UTC. A lighter bar is a run's tail (festival rewards, Diva week 3), which may run beside the next event. The game server reads the calendar every minute and writes each run's status and phases back; until it has, a run says "waiting for the game server". All times on this tab are UTC.

              Servers

              Status, the last restarts counter and how many players the game server reports. Logs hide secrets and mask player IPs. A restart takes two clicks; one restart per service every two minutes. The game server's restart warns players in Discord and in game for 10 minutes (the bot's status shows the countdown) before swapping and restarting; the in-game wrapper keeps its own 10-second countdown.
