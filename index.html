Hunt the Frontier again

Hunsterverse runs Frontier Z, the last version of Monster Hunter Frontier. Set up the game with the guide, then sign in here to link Discord and keep track of your hunters.

Start playing Linux guide
  1. Register a game account at hunstermonter.net.
  2. Install the client, the Hunsterverse patch and the launcher with the setup guide.
  3. Sign in on this page to link Discord, back up characters and see your item box.
