    Frontier guide

    A picture guide to Monster Hunter Frontier Z: town and menus, gear, monsters, ranks, events and the Hunting Road. Pick a section below, or start at the beginning.

    Written from the Monster Hunter Frontier guide by Fist, which describes Capcom's old official servers. Every section has "On Hunsterverse" notes saying where our server works the same and where it differs; the short version is on Hunsterverse vs the old servers.

    New here? Install the game first with the Play page, then read Basics and getting started and follow the Next link at the bottom of each page. Every section has its own contents list, so you can also jump straight to what you need.

    Different. The original guide was written for Capcom's official servers (mostly the Taiwanese ones), which closed in December 2019. Hunsterverse runs the final Japanese Frontier Z client with an English patch, so menu names can differ slightly. The game itself (monsters, gear, skills, quests) plays the same; what the server runs differs in places: every account has the Hunter Life, Extra, Premium and Net Cafe courses, the gacha is not set up, Diva Defense is not built yet, and players vote on the Hunting Road. Each section ends with a note like this one saying how that section compares.
