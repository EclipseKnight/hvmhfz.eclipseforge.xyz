Every update to Hunsterverse, newest first, by month and day. Each day groups its changes by topic, and each change shows when it went live.

Released updates are on the server, grouped by day and topic. Coming next is finished and tested, but not on the server yet. It goes live at a future server restart.

Each change shows when it went live, in UTC (and in your own time zone when your browser runs JavaScript). A change with only a date has no recorded time.

Where a fix says "the game waited forever", the game was waiting for an answer the server never sent, or the server answered in a form the game couldn't read. You saw a stuck "communicating" screen, or a list full of junk.

Most fixes come from checking exactly what the game expects from the server, so we don't have to guess. Only fixes we are sure of go live.
