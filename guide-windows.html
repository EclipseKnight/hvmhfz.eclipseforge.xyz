Monster Hunter Frontier Z on Windows

Mezeporta launcher and the Hunsterverse server, nothing else.

Tested with Mezeporta v1.5.4 and Windows 10/11. Launcher by LilButter, client patch by EclipseKnight. For the Linux version, see the Linux guide.

1. What you need

  • Windows 10 or 11, 64-bit.
  • The MHF-Z client, the folder named Monster Hunter Frontier Online (about 5.5 GB), containing dat/, mhf.exe, mhfo.dll, mhfo-hd.dll, mhl.dll and mhf.ini.
  • About 8 GB of free space on the drive you install to.
  • A Hunsterverse account. You create it yourself in the Mezeporta launcher (step 7): press REGISTER and choose a username and password.

Check the source. The base client comes from the community, not from Hunsterverse. The server patch is the part Hunsterverse actually maintains, and it must be applied after the client, as in the patch step. If a link looks different from these, verify it before you run anything.
Do not install into Program Files. Windows protects that folder, and the launcher writes into its own game directory. Use something like C:\Games\MHFZ.

2. Put the client in place

Copy (do not move) your client folder to C:\Games\MHFZ, so that dat and mhf.exe sit directly inside it:

C:\Games\MHFZ\ ├── dat\ │ └── mhfdat.bin ├── mhf.exe ├── mhfo.dll ├── mhfo-hd.dll ├── mhl.dll └── mhf.ini

3. Apply the client patch

Slow connection? Download the patch yourself, now. When the Mezeporta launcher checks for updates it has to download the patch (Frontier_Patch.zip, 50.9 MB) itself, and every file must arrive within 10 seconds. Below about 3 MB/s that fails with "Patcher failed to connect". Do not wait for that: download Frontier_Patch.zip in your browser (or let the script below do it) and apply it before you open the launcher for the first time. With the files already in place the launcher has nothing left to download. The same trick works for later patch releases: download the new zip by hand and unzip it over the game folder.

Open PowerShell and run this. It downloads the client patch, backs up every game file the patch replaces, then overlays the new ones.

$game = "C:\Games\MHFZ"

# 1. download and unpack the patch
$patchUrl = "https://github.com/EclipseKnight/hvmhfz.eclipseforge.xyz/releases/" +
            "download/client_patch/Frontier_Patch.zip"
$zip = "$env:TEMP\Frontier_Patch.zip"
Invoke-WebRequest -Uri $patchUrl -OutFile $zip
Expand-Archive -Path $zip -DestinationPath "$env:TEMP\Frontier_Patch" -Force
$src = (Get-Item "$env:TEMP\Frontier_Patch\Frontier_Patch").FullName.TrimEnd("\")

# 2. back up every game file the patch replaces, into original-files\ (only the first
#    time: running this again keeps the original files, not patched ones)
Get-ChildItem $src -Recurse -File | ForEach-Object {
  $rel = $_.FullName.Substring($src.Length + 1)
  $orig = Join-Path $game $rel
  $backup = Join-Path "$game\original-files" $rel
  if ((Test-Path $orig) -and -not (Test-Path $backup)) {
    New-Item -ItemType Directory -Force -Path (Split-Path $backup) | Out-Null
    Copy-Item $orig $backup
  }
}

# 3. copy the patch over the game
Copy-Item "$src\*" -Destination $game -Recurse -Force

The patch replaces mhf.exe, mhfo.dll, mhfo-hd.dll, mhl.dll and dat\mhfdat.bin, plus 79 files with the English text of the Diva storyline and a town's dialogue (in dat\load\, and dat\stage\st205.pac). The copies in original-files\ let you restore the original client at any time.

4. Install the launcher

Download Mezeporta-Windows.zip from the releases page and extract it into the same folder:

$mpUrl = "https://github.com/LilButter/Mezeporta/releases/" +
         "download/v1.5.4/Mezeporta-Windows.zip"
$mpZip = "$env:TEMP\Mezeporta-Windows.zip"
Invoke-WebRequest -Uri $mpUrl -OutFile $mpZip
Expand-Archive -Path $mpZip -DestinationPath "C:\Games\MHFZ" -Force

Afterwards Mezeporta.exe and the Mezeporta folder must sit next to dat, not inside a subfolder. If the zip unpacked into a nested folder, move the contents up one level.

Also install these two Microsoft runtimes, which the game engine needs:

  • Visual C++ 2015-2022 Redistributable, x86: vc_redist.x86.exe
  • DirectX End-User Runtime (June 2010): microsoft.com/download/details.aspx?id=35

5. First run

Double-click Mezeporta.exe. The first window has no server configured yet:

Windows may warn about the launcher. It is not code-signed, so SmartScreen can show "Windows protected your PC", and some antivirus products flag the game's DLLs. Only continue if you downloaded from the official releases page. If your antivirus quarantines a file, restore it and add an exclusion for C:\Games\MHFZ. Do not disable your antivirus entirely. Exclude the game folder before you apply the patch: mhf.exe is the file most often flagged, and a quarantine in the middle of a copy leaves the install half patched.

Open Configure Settings if you want to change the theme or language. On Windows there is no Wine prefix to configure, so the Linux-specific options do not apply.

6. Add the Hunsterverse server

Press ADD A SERVER and enter:

FieldValue

Host129.213.54.221

API mode shows the Hunsterverse launcher: news, banners, your mail and unclaimed gifts. If API mode won't log in, use the fallback: Launcher Port 53312 and Mode SignV1. It logs in and plays the same, without the news and banners.

7. Log in and play

Select Hunsterverse in the Server Selection dropdown, type your own account name and password, and press LOG IN. Choose a character, then launch.

No account yet? In the Mezeporta launcher press REGISTER, choose a username and password, then log in with them. Do not just type a new name into LOG IN: in API mode (the default) the server refuses a name that does not exist.

Usernames and passwords are case-sensitive. Always type them exactly the same way: Hunter and hunter are different names, and logging in with other capitalisation does not open your account (it can look like a lost save).

The launcher window closes when the game starts. That is normal. The game window is titled MONSTER HUNTER FRONTIER Z.

9. Files and folders

C:\Games\MHFZ\ ├── dat\ game data (patched mhfdat.bin) ├── mhf.exe mhfo.dll mhfo-hd.dll mhl.dll mhf.ini ├── original-files\ backups of the files the patch replaced │ └── dat\mhfdat.bin ├── Mezeporta.exe launcher ├── xinput1_3.dll controller support ├── XInputPlus.ini └── Mezeporta\ launcher settings, fonts, cache └── config.json server list and settings
Updating the launcher later: extract a newer Mezeporta-Windows.zip over the same folder. Your Mezeporta\config.json keeps the server list and settings, so back that folder up before a major update.

Appendix: English text and language

MHF-Z is a Japanese game. The English translation is not a separate installer: the text lives in the game's data files in dat\ (mhfdat.bin, mhfpac.bin, mhfinf.bin and the files in dat\load\). The Mezeporta launcher starts the game itself and never loads mhl.dll (that file belonged to the old Capcom launcher), so replacing mhl.dll changes nothing in game.

What the client patch already does. The patch from step 3 replaces dat\mhfdat.bin and adds the English Diva storyline and a town's dialogue. If your menus are English, you are done.

If your game is in Japanese. The patch step was skipped, or something put the original files back. Run step 3 again: it overlays the patched files and keeps your first backup in original-files\. The community client of step 1 already carries most of the English menus; a client copied from somewhere else may not.

Coverage is partial. Not everything is translated. Item names, NPC dialogue and event text often stay Japanese. That is the translation, not a broken install.

Fonts. If Japanese text shows as boxes, install noto-fonts-cjk and start the launcher with LANG=ja_JP.UTF-8 on Linux, or add the Japanese language pack on Windows (Settings, Time and language, Language and region, Add a language).

Two warnings from old client guides. Do not apply the hosts-file trick that circulates with the client pack: it points Capcom hostnames at 127.0.0.1, it is meant for self-hosted Erupe servers, and it will break name resolution for Hunsterverse. And Locale Emulator is only needed if the game refuses to start without a Japanese locale: Mezeporta launches the game itself, so try without it first.

Appendix: Discord linking and bot commands

Linking your game account to Discord gives you character backups and the bot commands. The account page does the linking:

  1. Open hvmhfz.eclipseforge.xyz.
  2. Sign in with the same username and password you use in the game.
  3. The Overview tab shows the command /link code:<code>, with your own code in it. In the Hunsterverse Discord type /link and paste the code into the code box.

Once linked, these slash commands work in the Hunsterverse Discord. The old !f commands are gone; type the / and pick the command from the list:

CommandWhat it does
/link code:<code>Links your game account to your Discord account. The code comes from the account page and is valid for 24 hours.
/backupSends you a zip backup of one of your characters in a DM (you pick the character).
/import backup:<file>Restores a character from a backup. Attach the zip /backup sent you as it is (do not extract it), or an Erupe export JSON from another server. You pick the target character, see a preview and confirm. Log out of the game first, and play the target character once before you import into it.
/password password:<new> confirm_password:<new> username:<account>Sets a new password for your game account (6 to 40 characters). Only you see the answer. This is the only way to reset a forgotten password, and only on an account that is linked to Discord.
Backups are a zip: send it as it is. Do not extract it and do not attach single BIN files. The account page's Backups tab can also download and import them (it says so when that is not available yet).
