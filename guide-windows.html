Monster Hunter Frontier Z on Windows

Mezeporta launcher and the Hunsterverse server, nothing else.

Tested with Mezeporta v1.5.4 and Windows 10/11. Launcher by LilButter, client patch by EclipseKnight. For the Linux version, see the Linux guide.

1. What you need

  • Windows 10 or 11, 64-bit.
  • The MHF-Z client, the folder named Monster Hunter Frontier Online (about 5.5 GB), containing dat/, mhf.exe, mhfo.dll, mhfo-hd.dll, mhl.dll and mhf.ini.
  • About 8 GB of free space on the drive you install to.
  • Your Hunsterverse account, registered at hunstermonter.net. You type the username and password yourself.

Check the source. The base client comes from the community, not from Hunsterverse. The server patch is the part Hunsterverse actually maintains, and it must be applied after the client, as in the patch step. If a link looks different from these, verify it before you run anything.
Do not install into Program Files. Windows protects that folder, and the launcher writes into its own game directory. Use something like C:\Games\MHFZ.

2. Put the client in place

Copy (do not move) your client folder to C:\Games\MHFZ, so that dat and mhf.exe sit directly inside it:

C:\Games\MHFZ\ ├── dat\ │ └── mhfdat.bin ├── mhf.exe ├── mhfo.dll ├── mhfo-hd.dll ├── mhl.dll └── mhf.ini

3. Apply the client patch

Open PowerShell and run this. It downloads the client patch, backs up the five files it replaces, then overlays the new ones.

$game = "C:\Games\MHFZ"

# 1. back up the files the patch replaces
New-Item -ItemType Directory -Force -Path "$game\original-files\dat" | Out-Null
Copy-Item "$game\mhf.exe","$game\mhfo.dll","$game\mhfo-hd.dll","$game\mhl.dll" `
  "$game\original-files\" -Force
Copy-Item "$game\dat\mhfdat.bin" "$game\original-files\dat\" -Force

# 2. download and unpack the patch
$patchUrl = "https://github.com/EclipseKnight/hvmhfz.eclipseforge.xyz/releases/" +
            "download/client_patch/Frontier_Patch.zip"
$zip = "$env:TEMP\Frontier_Patch.zip"
Invoke-WebRequest -Uri $patchUrl -OutFile $zip
Expand-Archive -Path $zip -DestinationPath "$env:TEMP\Frontier_Patch" -Force

# 3. copy the patch over the game
$src = "$env:TEMP\Frontier_Patch\Frontier_Patch\*"
Copy-Item $src -Destination $game -Recurse -Force

The patch replaces exactly five files: mhf.exe, mhfo.dll, mhfo-hd.dll, mhl.dll and dat\mhfdat.bin. The copies in original-files\ let you restore the original client at any time.

4. Install the launcher

Download Mezeporta-Windows.zip from the releases page and extract it into the same folder:

$mpUrl = "https://github.com/LilButter/Mezeporta/releases/" +
         "download/v1.5.4/Mezeporta-Windows.zip"
$mpZip = "$env:TEMP\Mezeporta-Windows.zip"
Invoke-WebRequest -Uri $mpUrl -OutFile $mpZip
Expand-Archive -Path $mpZip -DestinationPath "C:\Games\MHFZ" -Force

Afterwards Mezeporta.exe and the Mezeporta folder must sit next to dat, not inside a subfolder. If the zip unpacked into a nested folder, move the contents up one level.

Also install these two Microsoft runtimes, which the game engine needs:

  • Visual C++ 2015-2022 Redistributable, x86: vc_redist.x86.exe
  • DirectX End-User Runtime (June 2010): microsoft.com/download/details.aspx?id=35

5. First run

Double-click Mezeporta.exe. The first window has no server configured yet:

Windows may warn about the launcher. It is not code-signed, so SmartScreen can show "Windows protected your PC", and some antivirus products flag the game's DLLs. Only continue if you downloaded from the official releases page. If your antivirus quarantines a file, restore it and add an exclusion for C:\Games\MHFZ. Do not disable your antivirus entirely. Exclude the game folder before you apply the patch: mhf.exe is the file most often flagged, and a quarantine in the middle of a copy leaves the install half patched.

Open Configure Settings if you want to change the theme or language. On Windows there is no Wine prefix to configure, so the Linux-specific options do not apply.

6. Add the Hunsterverse server

Press ADD A SERVER and enter:

API mode shows the Hunsterverse launcher: news, banners, your mail and unclaimed gifts. If API mode won't log in, use the fallback: Launcher Port 53312 and Mode SignV1. It logs in and plays the same, without the news and banners.

7. Log in and play

Select Hunsterverse in the Server Selection dropdown, type your own account name and password, and press LOG IN. Choose a character, then launch.

No account yet? Type the username and password you want and press LOG IN: Hunsterverse creates the account on your first login. You can also register at hunstermonter.net first, which is the safer route if the login is refused.

The launcher window closes when the game starts. That is normal. The game window is titled MONSTER HUNTER FRONTIER Z.

8. Troubleshooting

VCRUNTIME140.dll or MSVCP140.dll missingInstall the x86 Visual C++ 2015-2022 redistributable. The game is 32-bit, so the x86 package is the one that matters.
SmartScreen blocks the launcherMore info, then Run anyway, but only for a file downloaded from the official releases page.
Antivirus deletes mhfo.dll or Mezeporta.exeRestore it from quarantine, then exclude C:\Games\MHFZ. Keep real-time protection on.

9. Files and folders

C:\Games\MHFZ\ ├── dat\ game data (patched mhfdat.bin) ├── mhf.exe mhfo.dll mhfo-hd.dll mhl.dll mhf.ini ├── original-files\ backups of the five patched files │ └── dat\mhfdat.bin ├── Mezeporta.exe launcher ├── xinput1_3.dll controller support ├── XInputPlus.ini └── Mezeporta\ launcher settings, fonts, cache └── config.json server list and settings
Updating the launcher later: extract a newer Mezeporta-Windows.zip over the same folder. Your Mezeporta\config.json keeps the server list and settings, so back that folder up before a major update.

Appendix: English text and language

MHF-Z is a Japanese game. The English translation is not a separate installer: it lives inside mhl.dll, the client's text layer, and that one file decides which language you see.

What the client patch already does. The Hunsterverse patch ships its own mhl.dll, so a normal install from the patch step is already translated. If your menus are English, you are done and should leave this file alone.

If your game is in Japanese. Your source client was untranslated, or something overwrote the patched DLL. Translation packs ship alternate builds of the same file. The pack this guide was written from contains two, mhfz_mhl.dll_custom and mhfz_mhl.dll_og. Swap the custom build in, keeping the server build safe:

cd C:\Games\MHFZ
Copy-Item mhl.dll mhl.dll.server
Copy-Item "C:\path\to\client pack\mhfz_mhl.dll_custom\mhl.dll" mhl.dll -Force

In that pack the _custom folder is the modified build to try first and _og is the untouched original. Folder names vary between packs, so use whichever pair came with yours.

If the game stops connecting after a swap, put mhl.dll.server back. The server patch build is what Hunsterverse expects, and a translation build from a different client version can be rejected.

Coverage is partial. Community translation updates do not translate everything. Item names, NPC dialogue and event text often stay Japanese even with the English DLL in place. That is the translation, not a broken install.

Fonts. If Japanese text shows as boxes, install noto-fonts-cjk and start the launcher with LANG=ja_JP.UTF-8 on Linux, or add the Japanese language pack on Windows (Settings, Time and language, Language and region, Add a language).

Two warnings from old client guides. Do not apply the hosts-file trick that circulates with the client pack: it points Capcom hostnames at 127.0.0.1, it is meant for self-hosted Erupe servers, and it will break name resolution for Hunsterverse. And Locale Emulator is only needed if the game refuses to start without a Japanese locale: Mezeporta launches the game itself, so try without it first.

Appendix: Discord linking and bot commands

Linking your game account to Discord gives you character backups and the bot commands. The account page does the linking:

  1. Open hvmhfz.eclipseforge.xyz.
  2. Sign in with the same username and password you use in the game.
  3. The page shows a command such as !f link <token>. Run it in the #mhfrontier channel of the Hunsterverse Discord.

Once linked, these commands work through a DM with the bot, except where noted:

CommandWhat it does
!f backup or !f backupcharDMs you a ZIP backup of your current character data.
!f import <files> or !f importcharRestores a backup: attach the BIN files from the ZIP. Extract the archive first; the bot skips 0 KB files.
!f resetpassword or !f pwDM the bot <newPassword> <confirmNewPassword> to change your password.
!f worldstats or !f wsIn the Frontier Discord channel: current world status, season and players online.
Backups are BIN files in a ZIP. Extract the archive before importing, and ignore the 0 KB entries. Command names come from the older guide; if one does not respond, check the pinned messages in #mhfrontier for the current list.
