    Set builder

    Build a set on the cards: click a piece or a decoration socket and pick from the list beside it, with what each choice changes. Or open Find sets, pick the skills you want and get sets that reach them. It runs in your browser on the game's own data; the address holds the set, so a link shares it. Signed in, load your character's gear and see what you are missing.

    Loading the game data.

    Another search: Frontier Set Searcher by d0t-execute also searches every piece for the skills you want: open it in its own tab (source, its issue page).

    The skill rules are the game's own, read from the client: the skill limit and which skills drop over it, automatic, Zenith and Tower Deco skills, which skills a weapon can use, defence and slots by armour level. Not counted: Tower armour plates, sigils of non-Tower weapons, food, Diva songs and other buffs, and special quest rules. A skill that looks wrong? Report it.
